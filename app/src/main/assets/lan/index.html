連結你的 PikminBee 手機

手機設定 → 電腦遠端控制 → 開啟。電腦與手機連接至同一可互通私人區網，在此輸入手機顯示的六位數配對碼，並由手機核准。

只使用可信任的私人區網。HTTP 尚未加密，不要從網際網路公開手機連接埠。關閉手機上的控制開關，連線即撤銷。
