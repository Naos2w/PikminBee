## A. 已定版的不可變更原則

1. **Map-first**：地圖填滿各裝置的可視畫布，控制元件疊放於地圖上；切換功能不能把地圖壓成一般表單附圖。
2. **桌面**：右側控制面板**預設展開**，基準寬度 **368px**；收合保留可重新展開的操作，左側四圖示導航精簡且不重複右側文字。
3. **平板**：**直向預設收合／橫向預設展開**右側抽屜，基準展開寬度 **326px**；旋轉裝置不得清空路線、選點或進度；使用者本次工作階段主動改過的展開狀態，優先保留。
4. **手機**：底部四個入口為**瞬移／路徑／尋花／設定**，Bottom Sheet **初始收合（把手區約56px）**；主導航約74px，需適配安全區和軟鍵盤。
5. **手機方案 A**：點任何未選的功能模式，切換內容並自動**半展開**；再次點目前選取模式**收合**；收合時點目前模式**半展開**。設定透過點擊進入，**不在三個功能頁的水平滑動序列中**。
6. **手機行走中**：即使 Bottom Sheet 收合，仍顯示精簡狀態、暫停／繼續及停止操作；停止須確認且不能誤觸。空閒時不顯示多餘控制條。
7. **三類位置明確分離**：最後經驗證的實體 GPS 歷史快照、當前虛擬 GPS、地圖選取草稿。圖示與文字不同；看標記不等於瞬移或切換模式。
8. **真實 GPS 保護**：僅在**手機明確授權分享**且有有效非模擬定位來源時，向已配對 Web 分享真實位置快照；自實體 fix 時間起**最多30分鐘**，逾期或撤銷即不提供精確座標。切到虛擬 GPS 後只可顯示舊快照及時間，不可偽稱即時位置。
9. **品牌視覺**：維持現有**礦石霧藍／蜂蜜色**與深淺色語意色彩；霧面、輕量、可讀，不新增霓虹、全畫面背景取樣、昂貴模糊或即時折射。
10. **安全動作**：任何地圖選點、收藏查看、GPS 標記或面板切換都不會自動瞬移、啟動行走或變更手機 GPS。路徑／尋花必須先預覽再確認開始。

## B. 定版畫面與狀態

| 情境 | 地圖佈局 | 預設控制 | 導航／互動 |
|---|---|---|---|
| 手機（例 390×740） | 全畫布 | Bottom Sheet 56px 收合 | 底部四功能；點模式半展開；重點收合 |
| 平板直向（例 690×920） | 全畫布 | 右側抽屜收合 | 左側功能圖示；點擊展開 |
| 平板橫向（例 830×650） | 全畫布 | 右側約 326px 抽屜展開 | 左側功能圖示；右側管理內容 |
| 桌面（例 1280×680） | 全畫布 | 右側約 368px 面板展開 | 左側精簡導覽；可一鍵收合 |

**實作參考斷點**：手機不超過 760px、平板 761–1060px、桌面至少 1061px；**不可僵硬套用原型的固定高度**。手機半展開約佔可用高度 40–45%，全展開至多約 80–85%；須根據 safe-area、螢幕高度、縮放與軟鍵盤動態計算。地圖維持在整個畫布後方，必要時調整浮動控制位置，避免被遮擋。

### 手機 Bottom Sheet 狀態機

| 目前狀態 | 操作 | 結果 |
|---|---|---|
| 首次載入 | — | `collapsed`，初選「瞬移」，地圖最大化 |
| `collapsed` | 點任一功能（含目前模式） | `half`，更新／保留模式 |
| `half` 或 `expanded` | 點目前模式 | `collapsed` |
| `half` 或 `expanded` | 點其他功能 | 切到該功能，回 `half` |
| `collapsed` | 把手向上拖 | `half` |
| `half` | 把手向上／下拖 | `expanded`／`collapsed` |
| `expanded` | 把手向下拖 | `half` |
| 任意 | 點／拖地圖 | 僅地圖選點或平移，不變更 Sheet/GPS |
| 面板內容 | 垂直捲動 | 只捲內容；不拖動 Sheet |
| 瞬移／路徑／尋花 | 有效水平滑動（建議≥72dp） | 切相鄰功能；不滑到設定 |
| 設定頁 | 水平滑動 | 不切模式；設定只能由明確點擊進入 |

**拖曳權限**：僅頂端可觸控把手負責 Sheet 高度手勢；地圖、表單、清單、縮放等互不搶事件。模式切換保留草稿、已選座標與路徑預覽狀態（但編輯路線點位時必須讓舊預覽失效）。

### 行走中精簡控制條（V2 最後新增的核准項目）

- 行走中 `MOVING`：顯示「行走中／本次估算步數」＋**暫停**＋**停止**；不顯示會造成誤按的「開始」。
- 已暫停 `PAUSED`：顯示「已暫停」＋**繼續**＋**停止**。
- 空閒／已停止：只留必要狀態，不常駐整排行走按鈕。
- 控制條浮在**已收合 Sheet 上方**，下面仍保留四功能導航，控制條與導航不得互相重疊；需避開系統手勢安全區。停止要有適當的確認機制；網頁斷線不應自行讓手機開始新路線。
- **現有 V2 HTML 尚未實作這個行走中精簡控制條**；它是已批准的後續工程規格，不得聲稱現有原型已完成。

## C. 座標、GPS、Wi-Fi 入口及收藏

### C1. 單欄座標

- 單一輸入框，格式 `25.033000, 121.565400`，順序固定為**緯度、經度**，和 Android App 相同。
- 可貼上半形／全形逗號或空白分隔的兩個數值，檢查緯度 -90～90、經度 -180～180，顯示清楚的錯誤。
- 地圖點選只填入草稿；按**確認瞬移**（必要時二次確認）才送指令。

### C2. 真實／虛擬／選取位置

- **實體 GPS 快照**：使用 Android 已取得且驗證為 `non-mock` 的定位（含來源時間、精度），手機在目前配對會話明確授權後才分享給 Web；Web 將它標成「最後真實位置／非即時」，可點擊移動地圖視角。
- **30 分鐘 TTL**：從真實 fix 的擷取時間起算，不是從打開網頁或進入模擬模式起算。逾期、撤銷授權或工作階段終止後不可繼續對新 Web 查詢提供精確座標；資料僅暫存在手機記憶體，不做永久收藏或瀏覽器長期儲存。
- **虛擬定位開啟後**：不得使用模擬定位樣本假裝取得新的實體位置；若無先前可信快照，顯示「尚未取得／請先回到真實模式取得」。不強迫自動切換 GPS。
- **虛擬 GPS**：使用獨立標記，反映實際 mock-provider 狀態，不與實體快照或草稿混淆。實體時區可獨立顯示，但不可把時區當成實體座標證明。
- **權限與風險**：保持私人區網配對、手機核准、會話期限與撤銷。現有 LAN HTTP 未加密，正式分享精確位置前需在手機明確告知區網傳輸風險；不得對公開網路開啟服務或將精確 GPS 自動提供給所有瀏覽器。

### C3. Wi-Fi 網址列與收藏

- Android Wi-Fi 設定的**網址欄右側**為 `複製` 圖示加文字；原本「複製網址」大按鈕改成**在預設瀏覽器開啟**。
- 保留配對碼、手機核准／拒絕、撤銷配對、已連線／過期／斷線／錯誤回饋。
- Web 地圖右上方保留收藏；搜尋、改名、刪除、載入路線、查看地圖不直接變更 GPS。地標／商家優先的自動建議地名維持可修改。

## British English summary

**PikminBee Wi-Fi Web V2 is design-frozen, not implemented.** Desktop controls open on the right by default; tablet controls start collapsed in portrait and expanded in landscape. Mobile opens with the bottom sheet collapsed: tapping a mode expands it halfway, tapping the same mode again collapses it, and Settings remains tap-only. When a walk is running, compact pause/resume and stop controls remain accessible. The web interface may show a phone-authorised, verified non-mock GPS snapshot for no more than 30 minutes, clearly labelled as historical. Implementation starts only after fresh approval and must pass browser, permissions, route-safety and physical POCO acceptance gates.
